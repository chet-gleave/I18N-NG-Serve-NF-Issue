# I18N-NG-Serve-NF-Issue

This repository's purpose was to demonstrate an issue with serving localized builds with @angular-architects/native-federation.



## Commands

```shell
npm run start:shell
```

```shell
npm run start:shell:fr
```

```shell
npm run start:shell:de
```
